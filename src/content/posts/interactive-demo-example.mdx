This post is an `.mdx` file, which means it can import components. Most posts should stay plain Markdown. When a post genuinely needs something interactive, add it as an island with `client:visible`: the JavaScript loads only on this page, and only once the demo scrolls into view.

<LineLength client:visible />

Everything above and below the demo is still ordinary Markdown.
